# Overview
## Project: Recipe Organizer

This project is part of my software development learning, applying concepts and syntax of the Kotlin language.  Through the creation of a recipe management application, I explored and implemented principles of object-oriented programming, manipulation of data structures (such as lists and maps) and data persistence using JSON files and the Gson library.

## Software Description

The Recipe Organizer application runs via command line designed to organize users' recipes. 
It allows users to:

- **View all existing recipes in JSON:** Display all existing recipes stored in the JSON file in a user-friendly format.
- **Add new recipes:** Allow users to input and store new recipes, including name, ingredients, instructions, and category.
- **Delete recipes** Enable users to remove recipes from their collection by specifying the recipe name.

# Development Environment
## Tools
-   **IntelliJ IDEA:** Integrated Development Environment (IDE) used for Kotlin development, providing code editing, debugging, and project management features.
-   **Git:** Version control system used for tracking changes and managing the project's source code.

## Programming Language and Libraries
- **Kotlin:** The primary programming language used for developing the application. Kotlin's concise syntax and interoperability with Java made it suitable for this project.
- **Gson:** A Java library used for serializing and deserializing Kotlin objects to and from JSON, enabling data persistence in JSON files.
